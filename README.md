# ❤️ Heart Disease Prediction using Logistic Regression

## Project Overview

This project predicts whether a patient is likely to have heart disease
using a Logistic Regression model. A Streamlit web application provides
an easy-to-use interface for entering patient details and viewing
predictions.

## Files

-   `app.py` -- Streamlit application
-   `Heart_disease_prediction_using_logistics_Regression.ipynb` -- Model
    training notebook
-   `heart_disease_model.pkl` -- Trained model (generate from the
    notebook)
-   `requirements.txt` -- Python dependencies

## Installation

``` bash
pip install -r requirements.txt
```

## Run the Application

``` bash
streamlit run app.py
```

## Features

-   Predicts heart disease from patient information
-   Simple Streamlit interface
-   Logistic Regression model
-   Fast predictions

## Technologies

-   Streamlit
